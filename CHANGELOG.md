# Changelog

All notable changes to this project will be documented in this file. Releases follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-13

Initial public prerelease.

### Added

- Streaming XLSX imports using Apache POI or fastexcel.
- One RocksDB column family per selected worksheet.
- Automatic or explicitly selected header rows and column subsets.
- JSON rows and multi-value secondary indexes.
- Versioned, atomically published imports with configurable generation retention.
- Standard-input support and concise verbose progress reporting.
- Technical documentation for consistent RocksJava readers.

[0.1.0]: https://github.com/neteagmbh/xlsx2rocksdb/releases/tag/v0.1.0
